# Copy And Message Catalog

## Purpose

This file captures message types and tone conventions worth preserving across future internal systems.

## Tone Principles

- Direct and operational
- Short enough for busy staff and students
- Clear about next action when a user is blocked
- Specific when validation fails

## Common Message Categories

### Authentication Errors

- Missing credentials
- Invalid email/password combination
- Email not allowed for login

### Validation Errors

- Required field missing
- File requirement missing
- Invalid date or inconsistent date range

### Permission And Gate Messages

- Route not available for this role
- TOS or policy acceptance required before continuing
- Form is read-only because the workflow is complete

### Empty States

- No files uploaded yet
- No notifications yet
- No recent students or no recent activity
- Student not found

### Confirmation-Oriented Copy

- Password was generated and must be stored now
- Status has changed
- Submission is ready for review

## Reuse Guidance

For future systems, keep a similar catalog for:

- auth messages
- workflow lock messages
- upload guidance
- reviewer request messages
- empty state phrasing
